`n`n`n`n`n`n`nTwo kinds of guardrail`n`n`n`nSoft`n`nGuides, but doesn't block`n`nA human, or an agent reading instructions, has to choose to follow it. Nothing stops the code from shipping if they don't.`n`nDocs · ADRs · skill knowledge · warning-level rules`n`n`n`nHard`n`nMechanically blocks the outcome`n`nBuild fails, commit is rejected, or the pipeline goes red. No one has to notice — the tooling refuses to proceed.`n`nAnalyzers set to error · arch tests · git hooks · required CI checks`n`n`n`n`n`n`n`n`n
