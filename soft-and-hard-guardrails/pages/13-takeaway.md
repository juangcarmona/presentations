# Every soft guardrail is a hard one someone hasn't written yet

The required CI check was a review comment first. The strict type check was a style guide entry first. Soft guidance works only as well as someone actually reads it. Hard guardrails don't need anyone to.

And once agents write your code, add the fourth stage: guard the verdicts, not just the code.

Discuss: what's our next soft → hard candidate — and is it a code guard or an agent guard?
