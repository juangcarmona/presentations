# Soft & Hard Guardrails

A Slidev presentation based on the two HTML concept decks in this folder and the Plain Concepts Chapters theme.

## Run locally

```bash
pnpm install
pnpm dev
```

Open the local URL printed by Slidev. The deck source is [slides.md](slides.md).

## Build or export

```bash
pnpm build
pnpm export
```

The original HTML concepts remain beside the Slidev source as visual references:

- [Soft & Hard Guardrails for Coding Agents.html](Soft%20%26%20Hard%20Guardrails%20for%20Coding%20Agents.html)
- [Guardrails — IDE Walkthrough.html](Guardrails%20%E2%80%94%20IDE%20Walkthrough.html)
