# Presentations

Repositorio personal para diseñar, construir y revisar presentaciones.

## Contenido

- `soft-and-hard-guardrails/`: primer deck en Slidev, construido sobre el tema Plain Concepts Chapters.
- `skills/`: skills versionadas para trabajar el contenido, Slidev, PowerPoint y QA visual.
- `docs/`: decisiones y referencias del workspace.

## Slidev

La plantilla base vive en [`C:\dev\plainconceptschapters\projects-brand-slidev-theme`](C:\dev\plainconceptschapters\projects-brand-slidev-theme). El deck usa el tema publicado directamente desde GitHub para poder actualizarlo sin duplicar el repositorio de la plantilla.

```powershell
cd soft-and-hard-guardrails
pnpm install
pnpm dev
```
