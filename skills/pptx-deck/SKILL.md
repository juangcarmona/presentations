# PPTX deck

Use for `.pptx` deliverables. The detailed engine is versioned in `skills/pptx-editor/`.

## Workflow

1. Establish the audience, language, title, date, and source material.
2. Prefer the blueprint pipeline: digest, plan, content blocks, compose.
3. Keep edits data-driven and preserve template geometry, brand styles, and editability.
4. Run the engine's QA script, render the output, and inspect the images for clipping, overlap, missing footer elements, and poor layout variety.
5. Keep generated outputs out of Git unless the user explicitly wants a checked-in deliverable.

Read the relevant guides under `skills/pptx-editor/guides/` only for the operation at hand. The copied engine is a maintained local fork of the upstream Plain Concepts skill and may be changed deliberately in later commits.
